# Migrate terminal launching off the deprecated API

## Request
Follow-up of "Support PhpStorm 2026.3 (build 263)": `TerminalCommandRunner.kt` opens terminals by
reflection through `TerminalView.getInstance(Project).createLocalShellWidget(String, String)` and
`ShellTerminalWidget.executeCommand(String)`. In PS-262.10968.76 and PS-263.7307.215 these still
exist but are deprecated (`TerminalView.getInstance` and all `createLocalShellWidget` overloads of
`TerminalToolWindowManager`), and the first attempt (`org.jetbrains.plugins.terminal.TerminalService`)
exists in neither build. Move to the non-deprecated terminal API before JetBrains removes the old
one, keep 251 working, and stop failing silently when no path works.
